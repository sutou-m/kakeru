# T-13 OCR確認・修正UI

## 担当エージェント
@ai-engineer @frontend-developer


## 目的
OCR＋AI分類結果をユーザーが確認・修正して保存できるUIを実装する。

## 前提チケット
- T-10・T-11・T-12完了済みであること

## 完了条件
- [x] `/receipts/upload` で画像をアップロードできる
- [x] OCR処理中にローディング表示が出る
- [x] 抽出結果が編集可能なフォームに表示される
- [x] 確認後、transactionsテーブルに保存される

## ページフロー
```
画像選択・プレビュー
  ↓ アップロード
OCR処理中（Spinner表示）
  ↓ 完了
確認フォーム（日付・金額・摘要・科目を編集可能）
  ↓ 「保存する」
収支一覧 /transactions にリダイレクト
```

## 実装内容
- ファイル入力：`accept="image/*"` でカメラ・ギャラリーどちらもOK
- プレビュー：アップロード前に画像サムネイル表示
- 処理状態：`pending` → `processing` → `done` / `error`
