## ページ構成（セクション順）

### 1. Heroセクション
- キャッチコピー：「確定申告を、もっとシンプルに。」
- サブコピー：「AIとスワイプ操作で、フリーランスの確定申告が完結するアプリ」
- CTAボタン：「無料ではじめる」→ `/auth/register`
- 背景：`#F5F0E8`（リネン）

### 2. 特徴セクション（3カラム）
| アイコン | タイトル | 説明 |
|---------|---------|------|
| ScanLine | レシートをスキャンするだけ | 撮影するだけでAIが金額・日付・勘定科目を自動入力 |
| Brain | AIが科目を自動分類 | 摘要から最適な勘定科目を提案。確認してタップするだけ |
| FileText | 申告書をそのまま出力 | 入力したデータから確定申告書をプレビュー・PDF出力 |

### 3. 対象ユーザーセクション
「こんな方におすすめ」
- はじめて確定申告をする方
- 毎年申告が面倒だと感じているフリーランス
- 領収書の管理が煩雑になっている個人事業主

### 4. CTAセクション
- 「今すぐKakeruをはじめる」
- ボタン：「無料で登録する」→ `/auth/register`

## デザイン方針
- 全体背景：`#F5F0E8`（リネン）
- カードの背景：`#FFFFFF`（白）
- アクセントカラー：`#E8884A`（テラコッタ）
- 見出しフォントサイズ：Hero h1は `text-4xl md:text-5xl`
- ポップになりすぎない落ち着いたトーン
- アイコンはlucide-reactを使用

## 注意事項
- Server Componentで実装（インタラクションなし）
- 画像は使用しない（アイコン＋テキストのみでクリーンに）
- `npm run build` 時にエラーが出ないよう確認
